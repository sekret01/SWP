# Changelog

## [0.0.5] - 31.05.2026

### [Added]

- функции для быстрого создания пакетов:
    - create_connect_package() - создание запроса на подключение к узлу
    - create_data_package() - создание запроса для передачи данных
    - create_close_package() - создание запроса на отключение от узла
